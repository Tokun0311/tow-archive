## Deploy

If you already work inside a GitHub Desktop project, **merge the contents of this `tow-archive/` directory into your existing repository**; do not nest one `tow-archive` folder inside another.

Suggested: close any open dev server, back up the existing project, copy the `src/` directory and this changelog into your project, **delete the obsolete `src/data/exhibitions/2026-01-21-05.md`** (its corrected replacement is `2026-01-24-05.md`), commit with GitHub Desktop, then push to the connected `main` branch. Cloudflare Pages will rebuild if it is connected to that GitHub repository. Build command: `npm run build`; output directory: `dist`.

The ZIP does not contain `node_modules`. To validate locally, run `npm install` and `npm run build` in the repository root.
