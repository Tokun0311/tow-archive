# 浮遊する器官
*Floating Organs*

**Artist:** yang02（やんツー）  
**Institution:** BUG, Tokyo  
**Exhibition:** 2026.02.25–04.05  
**Visited:** 2026.03.14  
**Type:** Installation / Mechanical Theatre / Media Art

### Exhibition Overview

《浮遊する器官》是艺术家やんツー以生成式AI、无人机和投石机为主要元素创作的机械剧场装置。

作品通过AI生成的对话，将两种具有不同历史背景的战争技术转化为剧场角色。机械装置的声音、动作与空间关系共同构成演出，使观众重新思考技术、战争、主体性及伦理之间的联系。

展览不仅呈现机器的自动化行为，也通过提示词、技术开发资料和研究记录，揭示作品背后的创作过程与人类劳动。

### Personal Observation

这次展览给我留下了很好的印象，尤其是机械剧场的形式与空间使用方式。

约20分钟的演出节奏十分合适，既让观众有足够时间进入机器之间的对话，又没有使整个观看过程变得冗长。

我特别喜欢展览在时间和空间上的组织方式。

观众首先观看一场由机器完成的剧场演出。表演结束后，空间被开放，观众可以走进原本的舞台，近距离观察机器、背景资料，以及创作过程中留下的各种痕迹。

这使作品不再只是一次完整的剧场呈现，也成为可以被进一步研究和理解的技术现场。

作品对技术与战争关系的批判相当集中而明确，同时保留了机械表演本身的趣味性与实验性。

总体而言，我认为这是一场完成度很高的展览，也体现了BUG在当代艺术展示和实验性实践方面的潜力。

### Curatorial Observation

展览通过两个连续的观看阶段，使观众经历不同的位置变化：首先作为与机器保持距离的剧场观众，随后作为能够进入现场、观察设备与制作痕迹的研究者。

这种结构使观看经验从对机器行为的感知，延伸至对技术系统及其生产过程的理解。

当机械装置同时作为表演者、技术设备和研究对象出现时，展览如何通过时间与空间结构改变观众对技术主体性和战争伦理的理解？
